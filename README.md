Distance Converter — QA & Testing Project

A desktop distance conversion application built with Python and Tkinter, with a focus on functional testing and software quality assurance.

About the Project

This project converts distances between supported units through a graphical user interface (GUI). It is also used as a practical project for exploring manual software testing and bug reporting.

QA Testing

* Test coverage: Positive values, zero, negative values, invalid input, and empty input.
* Testing techniques: Functional testing and boundary value analysis.
* Bug reporting: Issues are documented with reproduction steps, expected results, actual results, and severity.

Issues Under Investigation

* Negative input: Verify whether negative distances are accepted and whether this behavior matches the intended requirements.
* Invalid text input: Verify how the application handles non-numeric input and whether it displays a helpful error instead of crashing.

Detailed test cases and verified bug reports will be added as testing progresses.
